# Rocket 项目未来功能拓展建议

> 基于项目当前技术栈、业务定位（二级市场基本面研究）和已有路线图整理  
> 生成日期：2026-08-08  
> 对应版本：v0.11.2 · P1 已完成实现并通过自动化验收，Windows 人工回归待补

---

## 一、按阶段分类的建议

### 1.1 P1 后续增强（近期）

P1 完成后，以下功能可作为自然延伸：

| 功能 | 说明 | 价值 | 难度 |
|---|---|---|---|
| **底部状态栏** | 显示当前 Workspace、索引状态、Agent 连接状态、数据同步指示器 | 提升产品完成度，用户随时感知系统状态 | 低 |
| **命令面板（Command Palette）** | `Ctrl/Cmd + K` 快速搜索文件、笔记、Skills、切换 Workspace、执行操作 | 高频操作效率提升 10 倍以上，是专业工具的标配 | 低 |
| **全局快捷键系统** | 为新建笔记、保存、切换 Tab、聚焦 Agent 输入框等绑定快捷键 | 研究员双手不离开键盘即可完成核心操作 | 低 |
| **Workspace 导入/导出** | 将 Workspace 打包为 `.rocket` 文件（含笔记、资料、配置），支持导入恢复 | 便于备份、迁移和分享研究项目 | 低 |
| **HTML 沙箱增强** | 当前 CSP 较宽松，可引入更精细的子资源隔离和外部链接警告 | 安全加固，防止恶意 HTML 文档的攻击 | 中 |

### 1.2 P2 数据驱动期（已有规划，可深化）

README 中已列出 P2 规划，以下是补充和深化建议：

| 功能 | 说明 | 价值 | 难度 |
|---|---|---|---|
| **AKShare / yfinance 实际数据接入**（已有规划） | 完成数据源配置到真实数据调用的闭环，Agent 可直接查询财务/行情数据 | P2 核心目标，是"数据驱动"的基础 | 中 |
| **财务数据可视化（ECharts）** | 营收/利润趋势图、ROE 杜邦分析图、现金流结构图、PE/PB 历史分位图 | 基本面研究的核心产出，比纯文本更易洞察 | 中 |
| **同业对比视图** | 选择多家公司，并排对比关键财务指标（营收增速、毛利率、ROE 等） | 研究员高频需求，当前需手动做表 | 中 |
| **估值模型可视化** | DCF 估值的敏感性分析图（WACC/永续增长率双变量矩阵）、DDM 模型 | 让 Agent 生成的估值结果更直观、可调整 | 中 |
| **数据卡片/小部件** | 在投研概览中展示自选股的关键指标卡片（最新价、PE、市值、今日涨跌） | 快速扫盘，不需要打开行情软件 | 低 |
| **财报日历** | 显示自选股的财报披露日期、股东大会、分红除权等事件 | 帮助研究员提前安排研究计划 | 低 |

### 1.3 P3 高级研究期（已有规划，可扩展）

| 功能 | 说明 | 价值 | 难度 |
|---|---|---|---|
| **结构化研究模板**（已有规划） | 公司和行业研究的预设框架（商业模式、竞争格局、财务分析、估值、风险） | 标准化研究产出，降低新手门槛 | 中 |
| **财务模型与图表联动**（已有规划） | 在 Markdown 中嵌入可交互表格，修改假设后图表自动更新 | 真正的"活文档"，研究假设变更后全文联动 | 高 |
| **OCR 文档识别**（已有规划） | 对扫描版 PDF 和图片进行文字识别，纳入全文索引 | 解锁大量不可搜索的研报和财报图片 | 中 |
| **跨 Workspace 研究聚合**（已有规划） | 全局搜索和视图，跨项目追踪一家公司或一个行业的研究进展 | 研究员通常同时跟踪多个主题 | 中 |
| **知识图谱** | 基于全文索引提取公司、人物、产品、事件等实体，构建关联图谱 | 发现隐性关联（如供应链、竞争关系、股权结构） | 高 |
| **多文档对比分析** | 选择多篇研报或财报，Agent 自动提取各文档观点差异、数据矛盾 | 快速消化信息过载，发现市场分歧 | 中 |

### 1.4 P4 及更远期（创新性拓展）

| 功能 | 说明 | 价值 | 难度 |
|---|---|---|---|
| **自动化晨间简报**（已有规划） | 每日开盘前 Agent 自动生成自选股和行业要闻摘要 | 研究员每日第一杯咖啡时的信息入口 | 中 |
| **本地 LLM 支持（Ollama/LM Studio）** | 接入本地模型实现完全离线研究，保护敏感研究数据 | 满足合规要求（券商/基金内部数据不出境） | 中 |
| **本地 Embedding 模型** | 用于 Workspace 全文索引和语义搜索，不依赖云端 API | 降低长期成本，提升隐私和离线可用性 | 中 |
| **浏览器扩展** | Chrome/Edge 插件：一键保存网页到 Workspace、选中文字发送 Agent 分析、抓取财经数据 | 打通浏览器和桌面工作台的壁垒 | 中 |
| **语音输入与会议纪要** | 会议/路演录音转文字，Agent 自动提取关键投资要点和待办 | 研究员参加大量路演和调研，信息录入效率提升 | 中 |
| **研究快照/报告生成** | 将 Workspace 的研究过程一键导出为专业研报 PDF（含图表、引用、时间线） | 研究成果可直接用于内部汇报或对外发布 | 中 |
| **团队 Workspace 协作** | 基于 Git 或云同步的多人协作 Workspace，支持评论、@提及、变更追踪 | 研究团队内部协作，替代部分 Wiki/飞书文档 | 高 |
| **智能监控与告警** | 自选股异动监控（财报发布、重大公告、股价突破阈值），通过系统通知或邮件提醒 | 从"人找信息"变为"信息找人" | 中 |
| **多 Agent 协作编排** | 可视化编排研究流水线：数据 Agent → 分析 Agent → 写作 Agent → 复核 Agent | 复杂研究任务的自动化分解与执行 | 高 |
| **研究模板市场** | 用户可创建、分享和下载研究 Skills/模板，形成社区生态 | 降低新用户上手门槛，丰富研究框架库 | 中 |
| **PWA / 移动端适配** | 将 WebUI 拓展为 PWA，支持在平板/手机上查看研究摘要和接收通知 | 研究员出差、通勤时的轻量使用场景 | 中 |
| **专业数据终端接口** | 接入 Wind、同花顺 iFinD、Choice 等专业金融数据终端 | 服务专业机构投资者的高频数据需求 | 高 |
| **情绪数据聚合** | 整合雪球、东方财富股吧、Twitter/X 等社交媒体的投资者情绪指标 | 辅助判断市场情绪和预期差 | 高 |

## 二、按主题分类的拓展方向

### 2.1 数据层拓展

```
当前：AKShare (A/港股) + yfinance (美股)
    │
    ├──→ 国内专业数据
    │      ├── Wind（万得）— 机构级全品类数据
    │      ├── 同花顺 iFinD — 性价比高的替代方案
    │      └── 东方财富 Choice — 免费/低成本选项
    │
    ├──→ 国际数据
    │      ├── Bloomberg API — 顶级机构（远期）
    │      ├── Financial Modeling Prep — 已有规划，Free Tier
    │      ├── Alpha Vantage — 美股基本面/技术指标
    │      └── TradingView — 图表和技术分析
    │
    ├──→ 另类数据
    │      ├── 财经新闻 RSS/API（财新、华尔街见闻、Bloomberg）
    │      ├── 社交媒体情绪（雪球、东方财富、Twitter/X、Reddit）
    │      ├── 供应链数据（ImportGenius、Panjiva）
    │      └── 卫星/地理空间数据（远期）
    │
    └──→ MCP 生态
           ├── 财务数据 MCP Server
           ├── 新闻舆情 MCP Server
           ├── 行业数据库 MCP Server
           └── 宏观经济 MCP Server
```

### 2.2 Agent 能力拓展

```
当前：单 Agent 对话（Claude / DeepSeek / GPT）
    │
    ├──→ 多 Agent 协作
    │      ├── 数据 Agent — 专精数据查询和清洗
    │      ├── 分析 Agent — 专精财务分析和估值建模
    │      ├── 写作 Agent — 专精研报撰写和润色
    │      ├── 复核 Agent — 专精逻辑检查和数据校验
    │      └── 编排器 — 分解任务、调度 Agent、汇总结果
    │
    ├──→ Agent 记忆与学习
    │      ├── 长期记忆 — 记住用户的研究偏好和常用框架
    │      ├── 案例学习 — 从历史研究中学习成功/失败模式
    │      └── 个性化 — 根据用户风格调整输出语气
    │
    ├──→ Agent 工具扩展
    │      ├── 图表生成 — 根据数据自动生成可视化图表
    │      ├── 表格计算 — 在 Markdown 中执行财务模型计算
    │      ├── 网页抓取 — 实时获取最新公告和新闻
    │      └── 代码执行 — 运行 Python/R 进行量化分析
    │
    └──→ Agent 工作流
           ├── 晨间简报工作流 — 定时扫描 + 生成摘要
           ├── 财报季工作流 — 跟踪披露日历 + 自动下载 + 初筛分析
           ├── 调研准备工作流 — 收集公司资料 + 生成问题清单
           └── 估值更新工作流 — 定期重算 DCF/可比估值
```

## 三、优先级建议矩阵

### 高价值 + 低难度（尽快做）

| 功能 | 理由 |
|---|---|
| 命令面板（Command Palette）| 实现简单（已有索引数据），收益巨大，专业工具标配 |
| 全局快捷键 | 低代码量，显著提升操作效率 |
| Workspace 导入/导出 | 利用现有文件系统能力，增加数据可移植性 |
| 底部状态栏 | P1 明确排除的项，但实现简单，提升产品完整度 |
| 财报日历 | 纯展示型功能，数据来自现有数据源 |

### 高价值 + 中难度（重点规划）

| 功能 | 理由 |
|---|---|
| AKShare/yfinance 真实数据接入 | P2 核心，是"数据驱动"的基础前提 |
| 财务数据可视化（ECharts）| 基本面研究的刚需，图表比文字更易传达洞察 |
| 同业对比视图 | 高频需求，当前需手动做表 |
| OCR 文档识别 | 解锁大量扫描版 PDF，提升索引覆盖率 |
| 浏览器扩展 | 打通信息收集的最后一公里 |
| 本地 LLM / Embedding 支持 | 满足合规和隐私需求，降低长期成本 |

### 高价值 + 高难度（中长期投入）

| 功能 | 理由 |
|---|---|
| 知识图谱 | 发现隐性关联，构建真正的研究智能 |
| 多 Agent 协作编排 | 复杂研究任务的自动化，是 AI 原生工作台的核心差异化 |
| 财务模型与图表联动 | "活文档"是下一代研究工具的标志性能力 |
| 团队 Workspace 协作 | 从个人工具进化为团队平台，打开 B2B 市场空间 |
| 专业数据终端接口 | 服务机构客户的核心能力 |

### 低价值 + 高难度（谨慎评估）

| 功能 | 理由 |
|---|---|
| 移动端原生 App | Electron 桌面定位清晰，移动端可用 PWA 替代 |
| 实时交易接口 | 与基本面研究定位偏离，且合规风险高 |
| 自动化交易 | 完全偏离产品定位，合规和风控复杂度极高 |

## 四、与现有路线图的衔接建议

### P1 完成后立即启动

1. **命令面板 + 快捷键系统**：作为 P2 正式开启前的"体验提升包"，低投入高回报
2. **ECharts 图表库接入**：为 P2-3 "K 线、行情与财务数据视图" 做准备

### P2 期间并行推进

1. **本地 LLM / Embedding**：与数据接入并行，不阻塞主线
2. **浏览器扩展**：与数据层建设并行，扩大信息输入面
3. **OCR**：利用已有文件系统，提升索引质量

### P3 期间重点突破

1. **知识图谱**：基于 P1-6 全文索引和 P3-1 结构化模板的数据积累
2. **多 Agent 协作**：基于 P1-7 Agent 写入能力和 P2 Skills 的成熟
3. **团队 Workspace**：基于个人 Workspace 的稳定基线

### P4 及远期

1. **社区生态**：Skills 市场、模板市场，形成网络效应
2. **企业版功能**：SSO、审计日志、SLA、专属支持

## 五、结语

Rocket 的核心差异化在于：**将 AI Agent 深度整合到基本面研究的完整工作流中，而非简单的"聊天+数据"拼接**。

最值得优先投入的方向是：

1. **数据可视化** — 让 Agent 的分析结果"看得见、调得动"
2. **多 Agent 协作** — 让复杂研究任务从"人驱动"进化为"Agent 编排"
3. **本地 AI 能力** — 满足机构合规需求，降低长期运营成本
4. **知识图谱** — 从"文档管理"进化为"关系洞察"

这些方向共同指向一个目标：**Rocket 不仅是一个工具，而是一个会思考、会学习、会协作的研究伙伴**。
